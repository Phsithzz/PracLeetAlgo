# 05. Stack & Queue / Deque (สแตกและคิว)

สองโครงสร้างข้อมูลเชิงเส้นที่มีกฎการเข้า-ออกของข้อมูลเฉพาะตัว และถูกใช้เป็นหัวใจของอัลกอริทึมขั้นสูงอย่าง Depth-First Search (DFS) และ Breadth-First Search (BFS)

---

## 🧠 มโนทัศน์สำคัญ (Core Intuition)

### 1. Stack (เข้าทีหลัง ออกก่อน - LIFO: Last-In, First-Out)
- เหมือนจานข้าวที่วางซ้อนกัน จานที่วางบนสุดจะถูกหยิบออกก่อน
- **การทำงานใน Python:** ใช้ `list` ธรรมดา
  - ใส่ข้อมูลเข้า: `stack.append(x)` — $O(1)$
  - ดึงข้อมูลออก: `stack.pop()` — $O(1)$
  - ดูตัวบนสุด: `stack[-1]` — $O(1)$
- **จุดสังเกตในโจทย์สัมภาษณ์:**
  - การจับคู่วงเล็บ (Bracket Matching)
  - คำนวณนิพจน์คณิตศาสตร์ (Reverse Polish Notation)
  - จำสิ่งที่ต้องทำย้อนกลับ (Undo / Call Stack)
  - หาตัวเลขถัดไปที่มากกว่าหรือน้อยกว่า (Monotonic Stack)

### 2. Queue & Deque (เข้าก่อน ออกก่อน - FIFO: First-In, First-Out)
- เหมือนแถวคิวซื้อตั๋ว คนที่มาต่อคิวก่อนจะได้รับบริการก่อน
- ⚠️ **ข้อควรระวังสำคัญมากใน Python:**
  - ห้ามใช้ `list.pop(0)` เด็ดขาด! เพราะการลบตัวหน้าสุดใน `list` ต้องเลื่อนสมาชิกทั้งก้อน ทำให้เสียเวลา $O(N)$
  - ต้องใช้ `collections.deque` (Double-ended queue) เสมอ:
    - ใส่ข้อมูลเข้าคิว: `queue.append(x)` — $O(1)$
    - ดึงข้อมูลออกจากหน้าคิว: `queue.popleft()` — $O(1)$
- **จุดสังเกตในโจทย์สัมภาษณ์:**
  - การท่องไปในกราฟหรือต้นไม้แบบทีละระดับชั้น (Breadth-First Search / BFS)
  - จัดการงานตามลำดับเวลา เช่น ระบบจำกัดคำขอ (Rate Limiter / Recent Calls)
  - การหาค่าเฉลี่ยในหน้าต่างเวลา (Moving Average)
